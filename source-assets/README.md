# Source assets (originals – not part of the website)

These are the original brand files. They are kept here unchanged and are **not** deployed.

| File | What it is |
|---|---|
| `lukas-ude-corporate-identity-sheet.pdf` | Corporate Identity Sheet (colours, typography, logo, image language, voice) |
| `lukas-ude-logo-board.webp` | logo system board with variants and applications |
| `lukas-ude-image-language-board.png` | image language mood board (from the CI sheet) |
| `lukas-ude-portrait-original.jpg` | original portrait photo |

Derived files used by the website:
- logo SVGs (vector trace of the logo board) → `/frontend/assets/brand/`
- portrait → `/frontend/assets/images/portrait/` (optimised automatically during the build)
- mood image crops → `/frontend/assets/images/mood/`
- CI project images → `/content/design/lukas-ude-brand-identity/`, `/content/design/brand-applications/`

For print production, use original vector logo files from the designer if available.
